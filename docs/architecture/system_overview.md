# System Architecture

## Directory Structure
- `app/`: Next.js 13+ App Router structure
    - `landing-pages/`: Route for landing page portfolio
    - `dashboard-systems/`: Route for dashboard portfolio
    - `workflow-automation/`: Route for workflow portfolio
- `public/`: Static assets
- `docs/`: Project documentation (God-Mode standard)
- `tasks/`: Task tracking
- `memories/`: Agent context

## Key Components
- **Root Layout:** `app/layout.tsx` - Base HTML structure
- **Home Page:** `app/page.tsx` - Main entry point
